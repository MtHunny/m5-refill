# m5-refill — v0.1 Preview

AIとのチャットで希望を相談し、M5（Micro 5、62 × 105 mm）の手帳リフィルを作るSkillです。SkillはAIへの指示書です。記録項目や見た目を相談して、ブラウザで確認・印刷できる単一のHTMLファイルを作ります。プログラミングやサーバーの準備は不要です。

標準はA4縦に8枚（2列 × 4行）、裏面は薄い2 mm方眼です。用途の違うリフィルの混在や、裏面の無地／方眼、方眼の間隔・濃さを相談できます。v0.1は試作版で、生成結果と印刷結果の確認が必要です。

## 作例をそのまま試す

| 作例 | 内容 |
| --- | --- |
| [workout](examples/workout.html) | 筋トレ記録8枚。裏面は2 mm方眼 |
| [weekly](examples/weekly.html) | 日曜〜土曜の予定・TODO・よかったこと＋週間レビュー。裏面は2 mm方眼 |
| [grid-2mm](examples/grid-2mm.html) | 両面とも全面2 mm方眼。裁断線は表面のみ |

GitHubのファイル表示はHTMLのソースです。ファイル画面のダウンロードボタン（Download raw file）で `.html` を保存し、ダブルクリックするか、ブラウザの「ファイルを開く」で開いてください。リポジトリ全体は「Code → Download ZIP」で取得し、展開して使えます。作例はCSS・SVG内蔵で、外部ライブラリやフォントのダウンロードなしで開けます。

## 自分用に作る

### ChatGPTなどの通常チャット

1. [SKILL.md](.agents/skills/m5-refill/SKILL.md) を開き、ダウンロードします（ZIPでは隠しフォルダー `.agents` 内にあります）。
2. 新しいチャットに `SKILL.md` を添付します。添付できない環境では、その全文を貼り付けます。
3. 例えば次のように依頼し、質問に答えます。

> このSKILL.mdに従って、必要なことを一問ずつ質問しながらM5リフィルを設計してください。用途は読書記録です。要件がそろったら、印刷できるHTMLファイルを作ってください。

完成したHTMLを保存してブラウザで開きます。ファイル生成に対応しないチャットでは、省略のないHTML全文を受け取り、テキストエディターで **UTF-8・拡張子 `.html`**（例：`refill.html`）として保存してください。`.html.txt` にならないよう注意します。修正は「記入欄を広くして」などと同じチャットで頼み、更新後のHTML全体を受け取ります。

### Codex

このリポジトリを取得し、Codexで作業フォルダーとして開きます。リポジトリ内の `.agents/skills/m5-refill/SKILL.md` がSkillとして認識される環境で、次のように明示して依頼します。

> $m5-refill を使って、読書記録用のM5リフィルを作ってください。

一覧に出ない場合は、リポジトリを開き直すか、「`.agents/skills/m5-refill/SKILL.md` を読んで、その指示に従って作ってください」と依頼してください。

## 印刷・裁断する

1. 保存したHTMLをブラウザで開き、**Ctrl + P（Macは⌘ + P）** を押します。3作例はいずれも2ページ（表・裏）です。余分なページや文字の欠けがないかプレビューで確認します。
2. **A4縦・倍率100%／実際のサイズ・余白なし・自動縮小オフ・ヘッダー／フッターなし**に設定します。「用紙に合わせる」は使いません。PDFにする場合は印刷先を「PDFに保存」にし、PDFを紙に印刷するときも100%を指定します。
3. 全2ページを両面印刷します。手動ならプリンターの説明に従って差し直します。長辺とじ／短辺とじや差し込む向きは、まず1枚で確認してください。現作例の裏面は方眼で、180°回転の厳密な補正はしていません。
4. 試し刷りで寸法と線の濃さを確認します。workout・weeklyは横50 mm／縦30 mmの目盛り、grid-2mmは方眼間隔を測ります。裁断線から紙の下端までの49 mmは位置ずれにも影響されるため、それだけで倍率を判断しません。
5. 表面の裁断線（上端から248 mm）で**下部49 mmだけ**を切り落とし、残った210 × 248 mmを横2列 × 縦4行に等分します。1枠は105 × 62 mm、通常向きでM5の62 × 105 mmです。枠間の裁断線はありません。折り目などで位置を確認して裁断し、必要に応じて穴を開けます。

寸法が違うときは、まず印刷設定を見直してください。紙・枠・裁断線を合わせるためにHTML全体を拡大縮小しないでください。

## 既知の制約

- HTMLは確認・印刷専用で、入力・編集画面はありません。変更はAIとの対話で行います。AIやチャット環境によって、指示への従い方・ファイル出力の可否が異なります。
- ブラウザ・OS・利用可能なシステムフォントで文字の見え方が変わります。フォント選択の改善はv0.1公開後の候補です。
- プリンターによって倍率・位置・両面のずれ・線の濃さが異なります。「余白なし」でも非印字領域は欠ける場合があります。全機種での印刷精度は保証していません。workoutには家庭用プリンターでの印刷実績がありますが、各自の環境で試し刷りしてください。
